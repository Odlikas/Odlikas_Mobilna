# Odlikaš v2 Diagram Set Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** A complete draw.io diagram set for Odlikaš v2: a flow diagram for every function of the parent app, kid app and backend, and a UML class diagram with every attribute of every class (41 database tables + the proposed Dart / Edge Function / native classes).

**Architecture:** Diagrams are generated from one Python source (`docs/diagrams/source/`) so they stay consistent and can be regenerated after a design change. Flows are cross-functional swimlanes (Kid app / Parent app / Server / External) laid out left to right by a layered algorithm; class diagrams are UML tables per database area or package. Output is one `.drawio` file per diagram, one combined multi-page file, and PNG exports with the XML embedded.

**Tech Stack:** Python 3 (stdlib only), draw.io XML (mxGraphModel), draw.io Desktop CLI (libavoid edge routing, PNG export), draw.io MCP (reference + preview).

**Spec:** "Odlikaš — Backend, Database & AI Cost Architecture", https://claude.ai/code/artifact/6b788518-e690-4c07-b377-f4e3ab935f14, plus the decided product rules (unlock, quizzes, flashcards, Slikaj i razumij, homework check, time requests, Premium) and Figma v2.

## Global Constraints

- Diagrams only. No product code, no scaffolding in `apps/`, `packages/` or `supabase/`.
- Labels in English; Croatian screen and feature names stay as in the app (Učenje, Slikaj i razumij, Odobri / Vrati, Ovo nije točno).
- Numbers must match the spec: 60 min unlock, +30 min grade 5, +1 h weekend for a 7-day streak, time requests 15/30/60, free 3 quizzes per ISO week, Premium caps 10 photo helps + 5 homework checks per child per day, photos deleted after 30 days, pairing code 6 chars / 10 min / single use, €10 + VAT/mo, €79 + VAT/yr.
- Colors: blue = step, yellow = decision, green = start/success, red = error/cancel, orange = external system / waiting, purple = Premium / AI (paid).
- Every flow path ends at a terminal; every decision has all its branches labelled.
- Class attributes use `name: type = default {constraint}`; PK / FK marked; enums written out.

## Review Focus

- A flow branch with no terminal (dead end) → the validator fails the build.
- A node no edge reaches (orphan) → validator fails.
- A table attribute missing compared with the spec → the class source is checked against the 41-table list.
- Offline / no internet and Premium-locked paths → every kid feature flow that needs the server or Premium shows them.
- Kid-blocking failure (AI wrongly says "wrong") → homework flow always routes doubt to the parent.
